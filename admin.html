在这里写文章、发布、删除，都会直接更新到博客网站（cctv20.github.io），一两分钟后生效。这个页面本身不会被搜索引擎收录。

第一步：填入 GitHub 令牌

令牌只保存在你这台设备的浏览器里，不会上传到别处。没有令牌的话，按页面下方“怎么拿令牌”做一次就行。

怎么拿令牌：登录 GitHub 后打开 Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。名字随便填；Repository access 选 Only select repositories，勾选 cctv20.github.io；Permissions 里把 Contents 设为 Read and write；生成后复制令牌粘到上面。
